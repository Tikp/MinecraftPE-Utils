# How to setup the shortcut:

This shortcut uses a few "workarounds" to allow the use
of the shortcut without exiting minecraft

So, I found that using the accesibility setting
**Assistive Touch** works very well. But it 
requires a quick setup:

**You MUST have the shortcut downloaded first!**

# IMPORTANT:
MAKE SURE YOU GO INTO "ASSISTIVE TOUCH DISABLER" 
AND ENABLE THE AUTOMATION
Or the menu will stay on when you exit

ALSO:

ADDING THE LAUNCHER TO YOUR HOMESCREEN LETS YOU QUICKLY RUN 
MCPE WITH THE MENU ALREADY READY!


**Steps**:
Open Settings on your iPhone,
Go to "Accessibility", look for "touch",
Press "Assistive Touch", and then "Customize Top
Level Menu",
Set the amount of buttons (icons) to 1,
Select the only icon (should be in the middle), and set it to  "Minecraft PE Utils (NOT THE LAUNCHER!)

Now when you run the launcher you can press the button, and dont worry the automation that is included in the installer shortcut turns it off when you exit minecraft.
